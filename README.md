# Ведение документации по практикам

Программа кафедры ПМИ КНИТУ-КАИ: план практик и отчёт из Excel и Word, правки на экране, файлы в локальной SQLite. Окно называется Project P. Что делают кнопки, написано на вкладке «Руководство» ([help.html](help.html)).

## Запуск

Windows 10, Python 3.11, зависимости через [uv](https://docs.astral.sh/uv/).

```powershell
uv sync
copy .env.example .env
uv run python main.py
```

В `.env` нужен код регистрации. Пока строка пустая, обычное имя не зарегистрировать и пароль по коду не сменить. Имя из `RESERVED_ADMIN` (в примере это `admin`) заводится и без кода: если такого преподавателя нет, карточка создастся сама. Код общий на кафедру, по нему меняется пароль любой учётки.

«Запомнить меня» кладёт логин в `%USERPROFILE%\.magistr_project\remembered_username` и в следующий раз пропускает окно входа. На общем компьютере галочку лучше не ставить. «Выйти» этот файл стирает. Удаление своей учётки в кабинете текущий пароль не спрашивает.

```powershell
uv run ruff check .
uv run pytest
```

## Папки

| Путь | Что там |
| --- | --- |
| `DB/maindatabase.db` | Пользователи, преподаватели, старосты, документы. Если файла нет, создаётся при запуске |
| `Saves/` | То, что записала кнопка «Сохранить». Повторное сохранение старый файл не затирает |
| `Shablons/` | Шаблоны Word |
| `Example/` | Учебные Excel и Word, см. [Example/README.md](Example/README.md) |
| `logs/app.log` | Ошибки, без паролей |

`DB` и `Saves` в репозитории специально: это учебный пример, пароли в базе только хешем. В `.gitignore` их нет.

`View/workspace.py`, `View/appearance.py` и `View/res_rc.py` собраны из Qt Designer. Правки интерфейса делаются в `.ui`, эти три файла руками не правят.
