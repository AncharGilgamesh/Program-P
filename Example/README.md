# Пример

Кафедра ПМИ, 2025/2026 учебный год. Бакалавриат `01.03.02`, магистратура `01.04.02`.

| Группа | Курс | Практика | Срок |
| --- | --- | --- | --- |
| `4111`, `4112` | 1 | ознакомительная, на кафедре | 08.09.2025–21.09.2025 |
| `4211` | 2 | технологическая, ООО «БАРС Груп» | 29.06.2026–26.07.2026 |
| `4311` | 3 | эксплуатационная, АО «АйСиЭл КПО ВС» | 15.06.2026–26.07.2026 |
| `4411` | 4 | преддипломная, ООО «Татнефть-Цифровое развитие» | 09.02.2026–22.03.2026 |
| `4151` | 1, магистратура | научно-исследовательская работа | 08.09.2025–05.10.2025 |
| `4251` | 2, магистратура | практика по получению навыков НИР | 09.02.2026–08.03.2026 |

| Файл | Куда |
| --- | --- |
| `таблица_практик.xlsx` | План → «Загрузить таблицу». Листы «Бакалавриат» и «Магистратура» |
| `нагрузка.xlsx` | План → «Загрузить нагрузку», после таблицы |
| `план.docx` | «Загрузить план» на странице плана или отчёта. Места, договоры и часы уже проставлены |
| `отчёт.docx` | Отчёт → «Загрузить отчет». Собрания, явка и оценки уже заполнены |

После таблицы место проведения — «Кафедра», закупка — «нет». После нагрузки у `4111` будет `Г/б - 17`, `Пл. - 3`, `Целевики - 1`. У `4112` бюджет 18 и двое платных, у `4311` бюджет 14, платных 4 и один целевик.

В оценки попадают все семь групп: номер из четырёх цифр и начинается с 4. Осенью семестр нечётный, весной чётный: у `4111` сентябрь и семестр 1, у `4211` июнь и семестр 4, у `4411` февраль и семестр 8.
