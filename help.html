Система автоматизированного ведения документации по практикам

🔹 Назначение

Программа предназначена для автоматизации загрузки, редактирования и хранения документов по практикам. Упрощает работу кафедры и позволяет формировать отчеты по шаблонам.

🔹 Основные возможности

  • 📁 Загрузка данных из Excel
  • 📝 Редактирование вручную в таблицах
  • 📄 Формирование документов Word
  • 🗃 Хранение и защита документов в SQLite
  • 🕒 Срок хранения — 5 лет
  • 🔐 Защита от удаления
  • 📌 Открытие и удаление из интерфейса

🔹 Разделы таблиц

  1. План практик: Группы, направления, семестры, собрания
  2. Места прохождения: Город, место, количество студентов
  3. Распределение по руководителям: Преподаватель – место – группы
  4. Характер прохождения: Вид участия – офис/цех/лаборатория
  5. Оценки: Отл./Хор./Неуд./Не защитилось
  6. Руководители: ФИО, должность, оценки

🔹 Работа с базой данных

Раздел "База данных" позволяет просматривать, открывать и удалять документы. Можно установить флаг «Защищено», чтобы исключить удаление документа. Так же раздел позволяет работать с данными старост и преподавателей

🔹 Ввод данных вручную

Ввод осуществляется через диалоговые окна. Выбираются группы, вводится значение, и оно отображается в таблице.

🔹 Хранение

Файлы сохраняются в папке проекта и регистрируются в базе. Через 5 лет предлагается удалить документ. Защищённые записи не удаляются.

🔹 Рекомендации

  • 📦 Делайте резервные копии
  • 🔐 Устанавливайте защиту для важных файлов
  • ✅ Проверяйте введённые данные
