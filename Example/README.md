# Пример

Группы `4111`, `4211` и `4411`.

| Файл | Куда |
| --- | --- |
| `таблица_практик.xlsx` | План → «Загрузить таблицу». Два листа: бакалавриат и магистратура |
| `нагрузка.xlsx` | План → «Загрузить нагрузку», после таблицы |
| `план.docx` | «Загрузить план» на странице плана или отчёта |
| `отчёт.docx` | Отчёт → «Загрузить отчет» |

После таблицы место проведения — «Кафедра». После нагрузки у `4111` будет `Г/б - 10`, `Пл. - 2`, `Целевики - 1`, у `4211` бюджет 8, у `4411` бюджет 5 и один платный.

На отчёте у `4111` и `4411` сентябрь, семестры 1 и 7. У `4211` февраль и семестр 4. В оценки попадают все три группы: номер начинается с 4.

Собрать docx заново:

```powershell
uv run python Example/build_examples.py
```
