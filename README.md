# Ведение документации по практикам

Настольная программа кафедры ПМИ КНИТУ-КАИ. Собирает план практик и отчёт из Excel и Word, даёт поправить строки на экране и хранит готовые файлы в локальной базе SQLite.

Инструкция для того, кто работает в окне: вкладка «Руководство», текст в [help.html](help.html).

## Возможности

- Вход, регистрация и восстановление пароля. Пароль хранится как хеш bcrypt.
- Справочники преподавателей и старост.
- План практик: загрузка кафедральной таблицы, загрузка нагрузки, правка ячеек и сохранение в Word.
- Отчёт из шести таблиц, который собирается из сохранённого плана.
- Архив документов: открытие, защита от удаления и срок хранения 5 лет.

## Требования

- Операционная система: Windows 10 или новее. Основной сценарий проверялся на Windows.
- Python 3.11 или новее.
- [uv](https://docs.astral.sh/uv/getting-started/installation/) ставит зависимости из `uv.lock`.
- Интерфейс: PySide6. Остальные библиотеки: pandas, openpyxl, xlrd, python-docx, passlib и bcrypt. Версии указаны в `pyproject.toml`.

Сервер и сеть программе не нужны.

## Установка

Команды выполняются в каталоге, где лежит `main.py`.

```text
uv sync
copy .env.example .env
```

`uv sync` создаёт локальное окружение и ставит зависимости по `uv.lock`. Каталог `.venv` в репозиторий не входит.

В `.env` нужен код регистрации. Пока строка пустая, обычное имя не зарегистрировать и пароль по коду не сменить. Имя из `RESERVED_ADMIN` (в примере это `admin`) заводится и без кода: если такого преподавателя нет, карточка создастся сама. Код общий на кафедру, по нему меняется пароль любой учётки.

## Запуск

```text
uv run python main.py
```

Окно называется Project P.

«Запомнить меня» пишет логин в `%USERPROFILE%\.magistr_project\remembered_username` и в следующий раз открывает программу без пароля. На общем компьютере галочку лучше не ставить. «Выйти» этот файл стирает. Удаление своей учётки в кабинете текущий пароль не спрашивает.

## Структура

```text
main.py                      окно и переключение страниц
window_support.py            пути, срок хранения, журнал, запись в Saves
help.html                    текст вкладки «Руководство»
Models/dbhandler.py          SQLite: пользователи, преподаватели, старосты, документы
Models/datahandler.py        разбор Excel и Word
Models/docx_writer.py        запись строк в таблицы Word
Models/model.py              модели таблиц на экране
View/appearance.py           форма входа, собрана в Qt Designer
View/appearance_logic.py     вход, регистрация, чтение .env
View/workspace.py            главное окно, собрано в Qt Designer
View/plan_page.py            страница плана
View/report_page.py          страница отчёта
View/database_page.py        страница базы
View/planaddingdialogs.py    одно значение сразу нескольким группам
View/meetingdatedialog.py    дата собрания
View/prepod_dialog.py        карточка преподавателя
View/startosta_dialog.py     карточка старосты
tests/                       проверки разбора, учёток, документов и дат
Example/                     учебные Excel и Word кафедры ПМИ
DB/                          база
Shablons/                    шаблоны Word
```

`View/workspace.py`, `View/appearance.py` и `View/res_rc.py` собраны из Qt Designer. Их не правят и не форматируют: изменения интерфейса делаются в `.ui`, затем форма пересобирается.

Схема базы при запуске создаётся операторами `CREATE TABLE IF NOT EXISTS`. Отдельной миграции нет.

## Данные

| Путь | Назначение |
| --- | --- |
| `DB/maindatabase.db` | Пользователи, преподаватели, старосты и реестр документов. Если файла нет, создаётся при запуске |
| `Saves/` | Планы и отчёты кнопки «Сохранить». Повторное сохранение старый файл не затирает |
| `Shablons/shablon_plan.docx` | Шаблон плана. Данные пишутся в первую таблицу со строки 2 |
| `Shablons/shablon_otchet.docx` | Шаблон отчёта. Шесть таблиц заполняются со строк 1, 2, 2, 2, 4 и 2 |
| `Example/` | Учебные Excel и Word кафедры ПМИ за 2025/2026 год. Как прогнать, написано в [Example/README.md](Example/README.md) |
| `logs/app.log` | Ошибки. Пароли туда не пишутся |

`DB/maindatabase.db` и `Saves/otchet_test.docx` лежат в репозитории как учебный пример. Пароли в базе только хешем, почта и телефоны в справочнике пустые. В `.gitignore` эти пути не добавлены.

## Разработка

Зависимости приложения перечислены в `pyproject.toml` и зафиксированы в `uv.lock`. Pytest и ruff стоят в группе dev и в поставку программы не входят.

```text
uv run ruff check .
uv run pytest
```

Ruff проверяет каталог целиком, кроме трёх сгенерированных файлов интерфейса. Пример базы и `Saves` в репозитории остаются.

## Ограничения

- Код регистрации общий на кафедру. Кто его знает, задаёт новый пароль любой учётке.
- «Запомнить меня» пускает без пароля того, кто сидит в том же профиле Windows.
- Установщика нет. Запуск идёт через uv из каталога с `main.py`.
