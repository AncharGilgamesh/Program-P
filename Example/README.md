# Пример

Три группы, которые проходят тот же разбор, что кнопки программы.

| Файл | Что с ним делать |
| --- | --- |
| `таблица_практик.xlsx` | План → «Загрузить таблицу». Два листа: бакалавриат (`4111`, `4211`) и магистратура (`4411`) |
| `нагрузка.xlsx` | План → «Загрузить нагрузку» после таблицы. Дописывает бюджет, платное и целевиков |
| `план.docx` | Уже собранный план: таблица плюс числа студентов. Его открывает «Загрузить план» и на странице плана, и на странице отчёта |
| `отчёт.docx` | Отчёт из шести таблиц, собранный из `план.docx`. Его открывает «Загрузить отчет» |

Порядок в программе:

1. Зарегистрируйте пользователя из `RESERVED_ADMIN` в `.env`, если такой учётки ещё нет. В примере это `admin`.
2. Откройте «План» и загрузите `таблица_практик.xlsx`. В таблице три строки, место проведения — «Кафедра».
3. Загрузите `нагрузка.xlsx`. У `4111` появится блок `Г/б - 10`, `Пл. - 2`, `Целевики - 1`. У `4211` бюджет 8, у `4411` бюджет 5 и один платный.
4. «Сохранить» кладёт свой Word в `Saves` и в базу. Файл `план.docx` в этой папке — такой же результат, его можно открыть кнопкой «Загрузить план», не сохраняя заново.
5. Откройте «Генерация отчёта» и загрузите план. Шесть этапов заполнятся. Готовый вариант лежит в `отчёт.docx`.
6. На первом этапе у `4111` и `4411` сентябрь, семестры 1 и 7. У `4211` февраль и семестр 4. Пятый этап берёт все три группы: номер начинается с 4.

Собрать файлы заново из шаблонов программы:

```powershell
uv run python Example/build_examples.py
```
